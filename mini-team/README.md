按同目录的《多智能体小团队：实施计划》在这里逐步实现。代码、日志和评测都留在 MoA 仓库里。

当前步骤：第 1 步。写出十个命令行小任务和验收标准，并手写一遍确认做得到。

分工：

- Ellery 写需求、验收用例，并手写参考实现。
- 协作检查验收是否能判定对错，并在实现和验收不一致时一起查。

约定：

- 语言用 Python 3，只使用标准库。要改语言时先改这一条。
- 「需求」一节是以后给智能体的提示。里面写清命令、输入和输出，不写实现步骤。
- 「验收」一节是评测答案，不放进智能体提示词。
- 手写实现放在 `reference/<编号>/`，用来确认题目做得到。
- 预定调试组是 04、05、08，其余留考。手写通过之前，分组只是预定。

# 任务 03：JSON 摘要生成

- 状态：手写通过
- 分组：留考
- 入口：`python3 tool.py <input.json>`

规格已核对，手写参考实现通过本题全部验收用例。改需求或验收前先改状态。

输出键序固定为 `name`、`age`、`skill_count`。这不是字母序；按字母排序会得到 `age`、`name`、`skill_count`，那一版不能通过。

## 需求

编写 `tool.py`，从一个 JSON 对象提取摘要。程序只接收一个命令行参数：

```text
python3 tool.py input.json
```

规则：

1. 参数必须恰好是一个文件名，不能含 `/` 或 `\`。检查顺序：参数个数，文件名里有没有目录分隔符，文件是否存在，文件内容。
2. 文件是 UTF-8 JSON，不接受 BOM。只接受标准 JSON；`NaN`、`Infinity` 和 `-Infinity` 非法。顶层必须是对象。空文件非法。
3. 对象必须含有 `name`、`age`、`skills`。可以有其他字段，其他字段忽略。同一个对象里键名重复非法，包括嵌套对象和被忽略字段里的对象。键名在解码 JSON 转义后比较。
4. `name` 是非空字符串。不去掉首尾空格，不改变大小写。
5. `age` 必须是非负 JSON 整数，数字形式只能是 `0` 或 `[1-9][0-9]*`；`-0` 也非法。只接受不带小数点、不带指数的形式。`25.0`、`2e1` 非法。布尔值不是整数。负数非法。
6. `skills` 是数组，元素必须全是字符串。重复元素分别计数。空数组合法，个数是 0。
7. 输出一个 JSON 对象，只含三个键，顺序固定为 `name`、`age`、`skill_count`。`skill_count` 是 `skills` 的元素个数。
8. 输出使用紧凑格式，冒号和逗号后面没有空格。非 ASCII 字符直接以 UTF-8 输出，不写成 `\uXXXX`。字符串里的引号和控制字符按 JSON 规则转义。
9. 输出最后有一个 LF。成功时标准错误为空，退出码 0。

出错时标准输出为 0 字节，标准错误恰好是下面某一行加一个 LF，退出码 2。

- 参数个数不是一个：`ERROR: usage: tool.py input.json`
- 文件名含 `/` 或 `\`，或文件不存在：`ERROR: input file not found`
- UTF-8、JSON、顶层类型、缺字段、类型或整数形式不对：`ERROR: invalid JSON data`

## 验收

只给评测用。每个用例单独在空目录里运行。

### 用例 1：正常对象，忽略多余字段

准备 `input.json`：

```json
{
  "name": "Alice",
  "age": 25,
  "city": "Beijing",
  "skills": ["Python", "SQL", "Excel"]
}
```

命令：

```text
python3 tool.py input.json
```

期望：

- 退出码：0
- 标准输出：`{"name":"Alice","age":25,"skill_count":3}` 加 LF
- 标准错误：空

### 用例 2：中文和重复技能

准备 `input.json`，内容为一行：



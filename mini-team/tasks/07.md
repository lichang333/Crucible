# 任务 07：JSONL 记录去重

- 状态：手写通过
- 分组：留考
- 入口：`python3 tool.py <records.jsonl>`

规格已核对，手写参考实现通过本题全部验收用例。改需求或验收前先改状态。

每条输出对象的键序固定为 `value`、`id`。这不是字母序。

## 需求

编写 `tool.py`，按 `id` 去掉重复的 JSONL 记录。程序只接收一个命令行参数：

```text
python3 tool.py records.jsonl
```

规则：

1. 参数必须恰好是一个文件名，不能含 `/` 或 `\`。检查顺序：参数个数，文件名里有没有目录分隔符，文件是否存在，文件内容。
2. 文件是无 BOM 的 UTF-8。行分隔只认 LF 和 CRLF。文件末尾的一个行分隔不再多出一行。最后一行可以没有行分隔。空行非法，不能跳过。每行只接受标准 JSON；`NaN`、`Infinity` 和 `-Infinity` 非法。
3. 每一行必须是一个 JSON 对象，并且含有 `id` 和 `value`。可以有其他字段，输出时丢掉。同一个对象里键名重复非法，包括嵌套对象和被忽略字段里的对象。键名在解码 JSON 转义后比较。
4. `id` 必须是非空字符串。只含空格的字符串是非空的，要保留。不去掉首尾空格。
5. `value` 可以是任意合法 JSON 值，包括对象、数组、字符串、整数、小数、科学计数法、布尔值和 null。
6. 同一个 `id` 出现多次时，保留文件里最后一次出现的那条记录。
7. 去重后按 `id` 的 Unicode 码点升序输出。这不是拼音序，也不是忽略大小写的排序。`A` 在 `b` 前面，`a` 在 `张三` 前面。
8. 每行输出一个对象，只含 `value` 和 `id`，键序固定为 `value`、`id`。嵌套对象的键序保持输入里的顺序。
9. 整数形式的 JSON 数字按整数输出。含小数点或指数的数字，按 Python 3 `json.dumps` 的默认浮点格式输出。例如输入 `2e1` 输出 `20.0`，输入 `1.50` 输出 `1.5`。
10. 输出使用紧凑格式。标准输出编码为 UTF-8，不带 BOM。非 ASCII 直接输出，不写成 `\uXXXX`。零字节文件合法，标准输出为 0 字节。有记录时最后一行有 LF。成功时标准错误为空，退出码 0。

出错时标准输出为 0 字节，标准错误恰好是下面某一行加一个 LF，退出码 2。

- 参数个数不是一个：`ERROR: usage: tool.py records.jsonl`
- 文件名含 `/` 或 `\`，或文件不存在：`ERROR: input file not found`
- 编码、空行、JSON、类型、空 `id` 或重复键不合法：`ERROR: invalid JSONL`

## 验收

只给评测用。每个用例单独在空目录里运行。

### 用例 1：保留最后一次

准备 `records.jsonl`，末尾有 LF：

```jsonl
{"id":"a","value":10}
{"id":"b","value":20}
{"id":"a","value":30}
```

命令：

```text
python3 tool.py records.jsonl
```

期望：

- 退出码：0
- 标准输出两行，每行加 LF：`{"value":30,"id":"a"}`、`{"value":20,"id":"b"}`
- 标准错误：空

### 用例 2：按码点排序

准备 `records.jsonl`，末尾有 LF：

```jsonl
{"id":"张三","value":"A"}
{"id":"a","value":"B"}
{"id":"李四","value":"C"}
```

命令：

```text
python3 tool.py records.jsonl
```

期望：

- 退出码：0
- 标准输出三行，每行加 LF：`{"value":"B","id":"a"}`、`{"value":"A","id":"张三"}`、`{"value":"C","id":"李四"}`
- 标准错误：空

`a` 是 U+0061，`张` 是 U+5F20，`李` 是 U+674E。

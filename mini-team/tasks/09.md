# 任务 09：待办事项筛选

- 状态：手写通过
- 分组：留考
- 入口：`python3 tool.py <tasks.json> <reference_date>`

规格已核对，手写参考实现通过本题全部验收用例。改需求或验收前先改状态。

## 需求

编写 `tool.py`，找出需要提醒的未完成待办。程序接收两个命令行参数：

```text
python3 tool.py tasks.json reference_date
```

规则：

1. 检查顺序：参数个数，`reference_date` 是否合法，文件名里有没有 `/` 或 `\`，文件是否存在，文件内容。
2. `reference_date` 必须完全匹配 `YYYY-MM-DD`，并且是真实公历。规则与第 05 题相同。
3. 文件是无 BOM 的 UTF-8 JSON。只接受标准 JSON；`NaN`、`Infinity` 和 `-Infinity` 非法。顶层必须是数组。数组元素必须是对象，并且含有 `id`、`title`、`due_date`、`done`。可以有其他字段，其他字段忽略。同一个对象里键名重复非法，包括嵌套对象和被忽略字段里的对象；键名在解码 JSON 转义后比较。
4. `id` 是正整数。不接受 0、负数、布尔值、小数和指数。全部任务的 `id` 必须唯一；重复时即使其中一条会被筛掉，也是非法输入。
5. `title` 是非空字符串。不去掉首尾空格。
6. `due_date` 使用和第 2 条相同的日期规则。
7. `done` 必须是 JSON 布尔值。
8. 先验证数组里的每一项，包括之后不会输出的已完成任务和未来任务；任何一项字段、类型或日期不合法时，整个输入失败。验证完成后，只输出 `done` 为 false，且 `due_date` 小于或等于 `reference_date` 的任务。截止日期等于参考日期时也要输出。
9. 先按 `due_date` 升序，同一天再按 `id` 的数值升序。`3` 在 `20` 前面。
10. 输出是 JSONL。每行一个对象，只含 `id`、`title`、`due_date`，键序固定为这个顺序。紧凑格式，标准输出编码为 UTF-8，不带 BOM；非 ASCII 直接输出。没有结果时标准输出为 0 字节，不是只有换行。有结果时最后一行有 LF。成功时标准错误为空，退出码 0。
11. 顶层空数组合法，输出为空。

出错时标准输出为 0 字节，标准错误恰好是下面某一行加一个 LF，退出码 2。

- 参数个数不是两个：`ERROR: usage: tool.py tasks.json reference_date`
- `reference_date` 格式不对或日期不存在：`ERROR: invalid reference_date`
- 文件名含 `/` 或 `\`，或文件不存在：`ERROR: input file not found`
- JSON、字段、类型、任务日期或重复 `id` 不合法：`ERROR: invalid task data`

## 验收

只给评测用。每个用例单独在空目录里运行。

### 用例 1：过期和当天的未完成任务

准备 `tasks.json`：

```json
[
  {"id":1,"title":"Submit report","due_date":"2026-11-16","done":false,"note":"x"},
  {"id":2,"title":"Review budget","due_date":"2026-11-18","done":false},
  {"id":3,"title":"Read email","due_date":"2026-11-17","done":true},
  {"id":4,"title":"Pay invoice","due_date":"2026-11-17","done":false}
]
```

命令：

```text
python3 tool.py tasks.json 2026-11-17
```

期望：

- 退出码：0
- 标准输出两行，每行加 LF：`{"id":1,"title":"Submit report","due_date":"2026-11-16"}`、`{"id":4,"title":"Pay invoice","due_date":"2026-11-17"}`
- 标准错误：空

`note` 不输出。已完成的当天任务不输出。未来的未完成任务不输出。

### 用例 2：同一天按数值排序

准备 `tasks.json`：

```json
[
  {"id":20,"title":"Task B","due_date":"2026-11-17","done":false},
  {"id":3,"title":"Task A","due_date":"2026-11-17","done":false},
  {"id":11,"title":"Task C","due_date":"2026-11-17","done":false}
]
```

命令：

```text
python3 tool.py tasks.json 2026-11-17
```

期望：

- 退出码：0
- 标准输出三行，每行加 LF：`{"id":3,"title":"Task A","due_date":"2026-11-17"}`、`{"id":11,"title":"Task C","due_date":"2026-11-17"}`、`{"id":20,"title":"Task B","due_date":"2026-11-17"}`
- 标准错误：空

按字符串排序会把 `11` 排到 `3` 前面，本题不能那样排。

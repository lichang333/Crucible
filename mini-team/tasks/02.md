# 任务 02：CSV 成绩筛选

- 状态：手写通过
- 分组：留考
- 入口：`python3 tool.py <input.csv> <minimum_score>`

规格已核对，手写参考实现通过本题全部验收用例。改需求或验收前先改状态。

## 需求

编写 `tool.py`，筛出成绩达到最低分的记录。程序接收两个命令行参数：

```text
python3 tool.py input.csv minimum_score
```

程序只读这个 CSV，不修改它。

规则：

1. 检查顺序：参数个数，`minimum_score` 的格式，文件名里有没有 `/` 或 `\`，文件是否存在，文件内容。
2. 文件是 UTF-8 CSV，不接受 BOM。行分隔只允许 LF 或 CRLF；孤立 CR 非法。字段分隔符是英文逗号。不忽略逗号后面的空格。字段可以为空。字段只能是未引用字段或引用字段：未引用字段不能含双引号；引用字段必须以双引号开始和结束，字段内的双引号写成两个双引号；结束引号后只能紧接逗号或记录行尾。
3. 每条物理记录必须恰好三个字段，空白记录非法。字段内不允许出现 CR 或 LF；未闭合或位置不合法的引号非法。
4. 第一行是表头，必须恰好是 `name`、`score`、`class`，顺序固定，大小写敏感。
5. `score` 必须完全匹配 ASCII 十进制非负整数 `0` 或 `[1-9][0-9]*`。不允许正号、小数点、指数、空格、非 ASCII 数字或前导零。`0` 合法，`007`、`+90`、`85.5`、`９０` 非法。
6. `minimum_score` 使用同一套整数写法。比较时按任意精度整数，不转成浮点数。条件是 `score >= minimum_score`。
7. 输出保留符合条件的记录的原始顺序，不按成绩排序。
8. 输出仍是 CSV，表头固定为 `name,score,class`。只在字段含逗号、双引号或换行时加双引号；字段内的双引号输出成两个双引号。其他字段不加引号，逗号两侧不加空格。
9. 没有符合条件的记录时，仍然输出表头。只有表头的输入，输出也只有表头。
10. 成绩按规范十进制输出，不带前导零。标准输出使用 UTF-8，不带 BOM，换行使用 LF，最后一行有 LF。成功时标准错误为空，退出码 0。

出错时标准输出为 0 字节，标准错误恰好是下面某一行加一个 LF，退出码 2。

- 参数个数不是两个：`ERROR: usage: tool.py input.csv minimum_score`
- `minimum_score` 格式不对：`ERROR: invalid minimum_score`
- 文件名含 `/` 或 `\`，或文件不存在：`ERROR: input file not found`
- 编码、BOM、CSV 结构、表头、字段个数或成绩格式不对：`ERROR: invalid CSV`

## 验收

只给评测用。每个用例单独在空目录里运行。

### 用例 1：保留原始顺序

准备 `input.csv`，末尾有 LF：

```text
name,score,class
Carol,85,A
Alice,90,A
Bob,75,B
```

命令：

```text
python3 tool.py input.csv 80
```

期望：

- 退出码：0
- 标准输出：`name,score,class` 加 LF，`Carol,85,A` 加 LF，`Alice,90,A` 加 LF
- 标准错误：空

`Carol` 在输入里排在 `Alice` 前面，输出不能改成按分数从高到低。

### 用例 2：引号、逗号和等于最低分

准备 `input.csv`，末尾有 LF：

```text
name,score,class
"Smith, John",90,A
"Jane ""JJ""",80,"B,1"
Tom,79,C
```

命令：

```text
python3 tool.py input.csv 80
```

期望：

- 退出码：0
- 标准输出三行，每行加 LF：`name,score,class`、`"Smith, John",90,A`、`"Jane ""JJ""",80,"B,1"`
- 标准错误：空

`80` 达到最低分，要保留。`Tom` 的 79 不保留。

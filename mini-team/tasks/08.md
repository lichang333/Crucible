# 任务 08：库存变动汇总

- 状态：手写通过
- 分组：调试
- 入口：`python3 tool.py <inventory.txt>`

规格已核对，手写参考实现通过本题全部验收用例。改需求或验收前先改状态。

## 需求

编写 `tool.py`，把库存变动按商品编号累加。程序只接收一个命令行参数：

```text
python3 tool.py inventory.txt
```

程序只读这个文件，不修改它。

规则：

1. 参数必须恰好是一个文件名，不能含 `/` 或 `\`。检查顺序：参数个数，参数里有没有目录分隔符，文件是否存在，文件内容。
2. 文件是 UTF-8 文本。行分隔只认 LF 和 CRLF。读入时去掉这一处行分隔，不把 CR 留在行内。文件末尾的一个行分隔不再多出一行。最后一行可以没有行分隔。
3. 每一行必须恰好有一个逗号，形如 `商品编号,变动数量`。逗号两侧都不允许空白。空行非法。
4. 商品编号非空，只允许 ASCII 大写字母 `A` 到 `Z` 和数字 `0` 到 `9`。
5. 变动数量必须完全匹配 `0`、`[1-9][0-9]*` 或 `-[1-9][0-9]*` 其中一种；方括号里的数字只指 ASCII `0` 到 `9`。允许负数和零。正号非法。负号必须是 ASCII `-`（U+002D）。不允许小数、空格、前导零、`-0`，也不允许负号后面紧跟前导零。`0`、`3`、`-3`、`10` 合法。`+3`、`007`、`-0`、`-01`、`3.5`、`３` 非法。
6. 同一商品编号的数量全部累加。累加用任意精度整数，不能限制在 64 位以内。最终结果可以是负数或零。结果为零的商品也要输出。
7. 按商品编号的 ASCII 码点升序输出。这是整个字符串的字典序，不是按数字大小。因此 `A10` 在 `A2` 前面，`A` 在 `A1` 前面，`9Z` 在 `A001` 前面。
8. 每个商品编号只输出一行，格式是 `商品编号,累计变动数量`。逗号两侧没有空格，没有表头。数量用规范十进制：`0` 写成 `0`，负数写成减号加数字，没有正号和前导零。
9. 零字节文件合法，标准输出为 0 字节，退出码 0。有结果时，最后一条结果行后面恰好一个 LF。成功时标准错误为空。
10. 标准输出和标准错误都使用 UTF-8，换行只用 LF。

出错时标准输出为 0 字节，标准错误恰好是下面某一行加一个 LF，退出码 2。

- 参数个数不是一个：`ERROR: usage: tool.py inventory.txt`
- 参数含 `/` 或 `\`，或文件不存在：`ERROR: input file not found`
- 文件不是合法 UTF-8，或任一记录不符合上面的行、编号、数量规则：`ERROR: invalid inventory data`

## 验收

只给评测用。每个用例单独在空目录里运行。下面用「加 LF」表示该行以一个 LF 结束。失败时标准输出是 0 字节。

### 用例 1：同一商品累加

准备 `inventory.txt`，末尾有 LF：

```text
A001,10
A002,5
A001,-3
A003,8
A002,-2
```

命令：

```text
python3 tool.py inventory.txt
```

期望：

- 退出码：0
- 标准输出：`A001,7` 加 LF，`A002,3` 加 LF，`A003,8` 加 LF
- 标准错误：空


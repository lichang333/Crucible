# 任务 10：配置文件合并

- 状态：手写通过
- 分组：留考
- 入口：`python3 tool.py <defaults.ini> <overrides.ini>`

规格已核对，手写参考实现通过本题全部验收用例。改需求或验收前先改状态。

## 需求

编写 `tool.py`，把覆盖配置合并到默认配置上。程序接收两个命令行参数：

```text
python3 tool.py defaults.ini overrides.ini
```

规则：

1. 检查顺序：参数个数，然后先检查 `defaults.ini` 的文件名和是否存在，再检查 `overrides.ini`。文件名不能含 `/` 或 `\`。两个文件都检查通过后，先解析默认文件，再解析覆盖文件。
2. 两个文件都是无 BOM 的 UTF-8。行分隔可以是 LF 或 CRLF。文件末尾的一个行分隔不再多出一行。
3. 本题所说的空白字符集合与 Python 3 `str.strip()` 和 `str.lstrip()` 相同。空行允许。去掉行首空白后，以 `#` 或 `;` 开头的整行是注释。注释不输出。
4. 去掉首尾空白后，整行如果是 `[名称]`，就开始一个 section。名称再去掉首尾空白，中间空白保留。名称不能为空，也不能含 `[` 或 `]`。方括号外面不能再有别的字符。
5. section 名和键名都区分大小写。同一个文件里 section 名重复非法。两个文件里出现同一个 section 是合法合并。
6. 配置项必须属于一个 section，格式是 `key=value`。第一个 `=` 是分隔符，后面的 `=` 属于值。键和值都去掉首尾空白，中间空白保留。键不能为空，值可以为空。只含空白的值变成空值。
7. `#`、`;` 和 `%` 在值里都是普通字符。不做插值，也不识别行尾注释。
8. 同一个文件的同一个 section 里，键名重复非法，即使两个值相同。
9. 无法识别的行非法。没有键的 section 不输出。只有注释和空行的文件等于没有配置。
10. 合并时先采用默认文件。覆盖文件里相同 section、相同键的值替换默认值。覆盖文件里的新键和新 section 保留。默认文件里没有被覆盖的键也保留。
11. 输出的 section 按名称的 Unicode 码点升序。每个 section 内的键也按码点升序。格式是 `[section]` 后接 `key=value`。不输出注释。section 之间恰好一个空行。标准输出编码为 UTF-8，不带 BOM，换行使用 LF。最后一个键后面是一个 LF，不再多一个空行。
12. 两个文件都没有配置时，标准输出为 0 字节。成功时标准错误为空，退出码 0。输出使用 LF。

出错时标准输出为 0 字节，标准错误恰好是下面某一行加一个 LF，退出码 2。

- 参数个数不是两个：`ERROR: usage: tool.py defaults.ini overrides.ini`
- 任一文件名含 `/` 或 `\`，或任一文件不存在：`ERROR: input file not found`
- 任一文件的编码或 INI 结构不合法：`ERROR: invalid INI file`

## 验收

只给评测用。每个用例单独在空目录里运行。有两个 section 时，它们之间恰好一个空行。

### 用例 1：覆盖键并保留其余键

准备 `defaults.ini`，末尾有 LF：

```ini
[database]
host=localhost
port=5432

[app]
debug=true
name=demo
```

准备 `overrides.ini`，末尾有 LF：

```ini
[database]
host=db.example.com

[app]
debug=false
```

命令：

```text
python3 tool.py defaults.ini overrides.ini
```

期望：

- 退出码：0
- 标准输出依次是：`[app]`、`debug=false`、`name=demo`、一个空行、`[database]`、`host=db.example.com`、`port=5432`。除空行外每行加 LF，空行是额外的一个 LF。文件到 `port=5432` 的 LF 结束。
- 标准错误：空

`name` 和 `port` 没有出现在覆盖文件里，仍然保留。

### 用例 3：注释、空格和空值

准备 `defaults.ini`。最后一行的字节是 `note=`、三个 ASCII 空格、LF。文件其余部分末尾也有 LF。代码块中的 `<SP>` 是可见占位符，每个代表一个 ASCII 空格，准备文件时要把它替换成空格：

```ini
# comment
; also
  # note

[z]
beta = 2
alpha = 1

[a]
name = hello world
note=<SP><SP><SP>
```

准备 `overrides.ini` 为 0 字节。

命令：

```text
python3 tool.py defaults.ini overrides.ini
```

期望：

- 退出码：0
- 标准输出依次是：`[a]`、`name=hello world`、`note=`、一个空行、`[z]`、`alpha=1`、`beta=2`。`note=` 后面没有字符。
- 标准错误：空

`  # note` 是注释。`hello world` 的内部空格保留。

# 任务 01：词频统计

## 需求

编写 `tool.py`，统计一个文本文件里每个词出现的次数。程序只接收一个命令行参数：

```text
python3 tool.py words.txt
```

程序只读这个文件，不读标准输入，也不修改文件。

规则：

1. 参数必须恰好是一个文件名，不能含 `/` 或 `\`。检查顺序：参数个数，参数里有没有目录分隔符，文件是否存在，文件内容。
2. 文件按 UTF-8 解码，不接受非法字节。
3. 用 Unicode 空白切词，范围与 Python `str.split()` 不带参数时相同。连续空白只算一个分隔，不产生空词。标点不单独去掉，留在词里。
4. 统计前用 `str.lower()` 转换，不用 `casefold`。`The` 和 `the` 是同一个词。
5. 每个不同的词输出一行，格式是 `词 次数`，中间恰好一个 ASCII 空格。次数多的在前；次数相同的，按词的 Unicode 码点升序。
6. 有结果时，每一行包括最后一行都以 LF 结束。文件为空，或切词后一个词都没有时，标准输出为 0 字节，退出码仍是 0。
7. 标准输出和标准错误都使用 UTF-8，换行只用 LF。成功时标准错误为空。

出错时标准输出为 0 字节，标准错误恰好是下面某一行加一个 LF，退出码 2。

- 参数个数不是一个：`ERROR: usage: tool.py words.txt`
- 参数含 `/` 或 `\`，或文件不存在：`ERROR: input file not found`
- 文件不是合法 UTF-8：`ERROR: invalid text`

## 验收

只给评测用。每个用例单独在空目录里运行。下面用「加 LF」表示该行以一个 LF 结束。

### 用例 1：大小写、重复空白和相同次数

准备 `words.txt`，末尾有 LF：

```text
The cat and the dog
and THE  bird
cat
```

命令：

```text
python3 tool.py words.txt
```

期望：

- 退出码：0
- 标准输出：`the 3` 加 LF，`and 2` 加 LF，`cat 2` 加 LF，`bird 1` 加 LF，`dog 1` 加 LF
- 标准错误：空

`THE` 和 `the` 之间有两个空格，不能因此产生空词。`and` 排在 `cat` 前面，因为次数相同且 `a` 在 `c` 前面。

### 用例 2：标点留在词里

准备 `words.txt`，末尾有 LF：

```text
hello, world
Hello world.
```

命令：

```text
python3 tool.py words.txt
```

期望：

- 退出码：0
- 标准输出：`hello 1` 加 LF，`hello, 1` 加 LF，`world 1` 加 LF，`world. 1` 加 LF
- 标准错误：空

`hello` 是 `hello,` 的前缀，所以排在前面。`world` 同样排在 `world.` 前面。
